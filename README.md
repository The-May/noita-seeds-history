# Noita Daily Seed Archive

Archives the daily Noita seed data from Nolla's API (`https://takapuoli.noitagame.com/callback/`)
once per day via GitHub Actions, and publishes it as both a raw JSON file and a small static page
via GitHub Pages.
I could not find any tool that archives the seed and for me it would be nice to have this.

access via
https://the-may.github.io/noita-seeds-history/ for human eyes
or:
https://the-may.github.io/noita-seeds-history/seed-archive.json for machine eyes

## Notes
You can use https://github.com/Lymm37/noita-telescope for viewing the seed
